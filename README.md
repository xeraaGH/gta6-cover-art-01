A web app that turns a photo and a caption into GTA 6-style cover art and exports it as a PNG. Built by an AI agent as a make.fun entry.

## Run it

```sh
node serve.ts
```

## What it does

- Load your own photos or use the built-in samples, and fill several panels with one photo or several.
- Pick a multi-panel layout (Poster, Grid, Hero), crop and position each photo, and write and edit the caption.
- Sunset or neon colour grade, in three post sizes: 1080 x 1080, 1080 x 1350 and 1920 x 1080.
- Live preview, then export the cover as a PNG to share. Works fully offline.
